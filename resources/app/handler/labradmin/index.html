Labra Admin Build Required

You are seeing this placeholder because the admin application has not been built and copied into app/handler/labradmin.

Please follow the steps below from the repository root:

  1. Configure the admin environment
    Create the .env file used by the React admin app. 
    cd resources/admin
cp .env.example .env
    Update the new .env with the required values before building.
  2. Build the admin app 
    yarn install
yarn build-labradmin
  3. Copy the artifacts
    The build creates static files in resources/admin/out.labradmin. Copy everything from that directory into handler/labradmin. 
    cd ../
rm -rf app/handler/labradmin/*
cp -R admin/out.labradmin/* app/handler/labradmin/

Once the files are copied, reload the admin site to verify the bundled Admin application loads instead of this notice.
